一条命令接入

不需要编译，也不需要安装 Cheat Engine 本体。 wire.mjs 幂等、可重跑，每一步都留时间戳备份。 

# 在仓库根目录执行（目录名随意，判断依据是 package.json 的包名）
node wire.mjs

# 换 profile
node wire.mjs --profile web

# 显式指定内核目录
node wire.mjs --kernel D:/path/to/node-cheat-engine

# 卸载
node wire.mjs --unwire
内核仓库

前置条件

  • Windows x64
  • 内核存在且可 require（仓库子目录，或从 npm 装 @bingine/cemem）
  • DSH 桌面版，或 dsh web

验证是否激活

状态路由是只读的 —— 不加载内核、不读任何进程内存。返回 toolCount: 16 且列出全部 ce_* 即注册成功。

curl http://127.0.0.1:19387/cheat-engine/status
